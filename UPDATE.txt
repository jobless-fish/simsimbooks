사진 전용 인스타그램 섹션 업데이트

기존 인스타그램 피드 업데이트를 적용한 저장소에 이 ZIP의 4개 파일을 덮어쓰세요.
기존 data/instagram.json, instagram-utils.js와 assets/instagram 사진은 그대로 사용합니다.
Worker 재배포는 필요 없습니다.

git add index.html app.js style.css instagram.js
git commit -m "Simplify Instagram ribbon and photo lightbox"
git -c core.editor=true pull origin main --no-rebase
git push origin main

변경 내용
- INFO 다음 사진 섹션의 뒷 카드, 제목, 계정명, 날짜, REEL/POST 배지, 상단 INSTA 메뉴 제거.
- 사진이 초당 약 22px 속도로 천천히 왼쪽으로 무한 반복됩니다.
- 사진 아래에만 옅은 그림자를 적용했습니다.
- 클릭하면 사진만 확대됩니다. Instagram 임베드/본문/동영상/원문 메뉴는 표시하지 않습니다.
- 사진의 원래 비율을 유지하고 팝업 모서리에만 작은 라운드를 적용했습니다.
- 닫기 버튼, 배경 클릭 또는 Esc로 닫을 수 있습니다. 스크롤바는 표시하지 않습니다.
- 기기의 모션 줄이기 설정에서는 자동 흐름을 멈추고 가로 스크롤을 제공합니다.
- 현재 사진 12개 목록을 사용하며 새 게시물 자동 동기화는 추가하지 않았습니다.
