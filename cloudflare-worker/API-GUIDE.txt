심심한책방 관리자 화면 연결 명세 (events-1)

API 주소: https://simsimbooks-api.joblessfish.workers.dev
허용 웹사이트 출처: https://jobless-fish.github.io
관리자 화면과 웹사이트는 기존 GitHub Pages 저장소 안에 만듭니다.
서버의 ADMIN_ID, ADMIN_PASSWORD, GITHUB_TOKEN, SESSION_SECRET은 화면 코드에 넣지 않습니다.

1. POST /login
Content-Type: application/json
JSON: {"id":"사용자가 입력한 아이디","password":"사용자가 입력한 비밀번호"}
성공: {ok:true,token,expiresAt,expiresIn:3600}
이후 Authorization: Bearer <token> 사용.
토큰은 메모리에 두고 새로고침 시 재로그인하도록 구현. 비밀번호는 저장하지 않습니다.
로그아웃은 메모리의 토큰을 지웁니다. 발급된 토큰은 최대 1시간 유효합니다.

2. GET /session
Authorization 필요. 성공: {ok:true,role:"admin",expiresAt}.
401이면 토큰을 지우고 로그인 화면으로 돌아갑니다.

3. GET /events
Authorization 필요. 성공: {ok:true,events:[],revision:"커밋 SHA"}.
파일이 아직 없으면 빈 목록을 반환합니다.

4. POST /events — 신규 행사 등록
Authorization 필요. 본문은 FormData, Content-Type 헤더는 직접 지정하지 않습니다.
필드 id: crypto.randomUUID()로 생성한 UUID v4 문자열.
같은 등록을 재시도할 때 id와 metadata와 poster를 그대로 재사용해야 중복 저장을 막습니다.
필드 metadata: 아래 JSON을 JSON.stringify한 문자열.
{
  "title": "행사명",
  "startAt": "2026-12-01T14:00:00+09:00",
  "endAt": "2026-12-01T16:00:00+09:00",
  "location": "심심한책방",
  "description": "행사 소개. 일반 텍스트로 저장합니다.",
  "registrationUrl": "https://example.com/signup"
}
registrationUrl은 생략하거나 빈 문자열로 보낼 수 있습니다. 입력하면 HTTPS만 허용합니다.
날짜는 시간대를 명시합니다. 한국 시각 입력에는 +09:00을 붙이고 서버는 UTC ISO로 저장합니다.
시작/종료가 없는 경우를 임의로 만들지 않습니다. 종료는 시작보다 빠를 수 없습니다.
필드 poster: PNG/JPG/WebP 이미지 File 한 장. 최대 2MiB. SVG는 지원하지 않습니다.
이미지 픽셀 무결성/크기 변환은 화면에서 이미지 디코딩과 압축으로 처리합니다.
등록 버튼은 전송 중 비활성화하고 오류 시 입력 내용을 유지합니다.

성공: HTTP 201 {ok:true,created:true,event,commit,message}
같은 ID/내용 재전송: HTTP 200 {ok:true,created:false,event,commit,message}
실패: {ok:false,message,githubStatus?}
400: 입력 오류. 401: 재로그인. 403: 출처 또는 권한. 409: 충돌. 413: 용량 초과.
429: 요청이 많음. 1분 뒤 재시도. 502: GitHub/서버 오류. 동일 id로 재시도.

GitHub 저장 위치 (저장소 최상위 기준):
- data/events.json: {schemaVersion:1,events:[행사 객체,...]}
- assets/events/<행사 UUID>.png 또는 .jpg 또는 .webp
포스터와 목록은 하나의 커밋으로 저장됩니다. 기존 사이트 파일은 유지됩니다.
저장 성공은 GitHub 커밋 완료를 뜻하며, Pages 배포 완료를 뜻하지 않습니다.

5. 방문자 EVENTS 화면
페이지 기준 상대 주소 data/events.json을 가져옵니다. /data/events.json처럼 도메인 루트 경로를 쓰지 않습니다.
관리자 화면이 하위 폴더이면 ../data/events.json처럼 사이트 루트에 맞춥니다.
행사의 poster도 사이트 루트 기준 상대 경로로 표시합니다.
404면 아직 등록된 행사가 없다는 상태로 처리합니다.
텍스트는 textContent로 출력하고 description을 innerHTML에 넣지 않습니다.
날짜는 Asia/Seoul 시간대로 표시합니다.
외부 신청 링크에는 rel="noopener noreferrer"를 적용합니다.
저장/읽기만 연결한 백엔드 단계이며, 기존 홈페이지 EVENTS 표시와 관리자 화면은 별도 구현이 필요합니다.
수정/삭제 API는 이번 버전에 포함하지 않았습니다.

6. 배포
ZIP의 worker.mjs와 wrangler.jsonc를 기존 cloudflare-worker 폴더에서 교체합니다.
npx wrangler deploy --keep-vars
기존 Secret/일반 변수는 유지됩니다. 비밀 값을 파일로 만들지 않습니다.
설정의 LOGIN_LIMITER는 같은 위치에서 로그인과 행사 등록을 각각 1분 5회 수준으로 제한합니다.
Cloudflare 카운터는 전역의 정확한 5회 제한이 아닌, 위치별 근사 제한입니다.
GitHub에 올리기 전 .gitignore에 아래 줄을 추가합니다.
cloudflare-worker/.wrangler/
cloudflare-worker/node_modules/
cloudflare-worker/.dev.vars
cloudflare-worker/.dev.vars.*
cloudflare-worker/.env
cloudflare-worker/.env.*
